What each layer proves

check_interpreter

Lifecycle, Python execution, namespace persistence, fresh isolation, recoverable errors, host tools, authority revocation, typed SUBMIT, immediate termination after accepted SUBMIT, and terminal shutdown.

check_bind

The optional native binding extension atomically replaces tools and output fields, copies caller-owned inputs, and revokes removed authority.

check_execution_instructions

The optional backend description is a stable, nonempty string. It is metadata for the action model—not a per-turn input.

check_rlm

A real deterministic dspy.RLM uses any offered execution instructions, a user host tool, an LM-shaped host callback, typed output, factory ownership, and shutdown.

check_flex_facade

A real optimized dspy.Flex source program invokes a host predictor and tool, transports values, and survives save/load without serializing its interpreter.
